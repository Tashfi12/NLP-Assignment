Task 1: Scientific Spelling Correction System

**Scientific Spelling Correction System | NLP with Python**

Developed a Python-based spelling correction system for scientific writing using an arXiv research corpus. The system combines tokenization, dictionary-based spell checking, Damerau–Levenshtein edit distance, and unigram/bigram language models to detect and correct non-word and contextual spelling errors. Implemented an interactive Tkinter GUI for text input, error highlighting, and correction suggestions.

Link of Dataset: https://www.kaggle.com/datasets/Cornell-University/arxiv

Technologies: Python, NLP, Damerau–Levenshtein Distance, N-gram Language Models, Tkinter.

Task 2: Movie Review Sentiment Analysis

**Movie Review Sentiment Analysis | NLP with Python**

Developed a sentiment classification system using the IMDB dataset of 50,000 movie reviews to classify reviews as positive or negative. Implemented and compared five models: Naive Bayes, Logistic Regression, Linear SVM, Random Forest, and Bidirectional LSTM. Applied text preprocessing, TF-IDF vectorization, hyperparameter tuning, and performance evaluation using accuracy, precision, recall, and F1-score. Deployed the best-performing tuned Linear SVM model using Streamlit for real-time sentiment prediction.

**Best Result:** 89.90% accuracy and 89.99% F1-score using tuned Linear SVM.

Link of Dataset: https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews

Technologies: Python, NLP, NLTK, Scikit-learn, TensorFlow/Keras, TF-IDF, Streamlit.
